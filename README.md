#  Análisis de Colombianos Detenidos en el Exterior (2018–2025)

Este proyecto consiste en un ecosistema analítico interactivo (Dashboard) diseñado para explorar, limpiar y modelar estadísticamente las dinámicas demográficas, temporales y espaciales de los ciudadanos colombianos privados de la libertad en el extranjero. 

Desarrollado para la **Feria de Proyectos de Ciencia De Datos** de la **Universidad Tecnológica de Bolívar (UTB)**.

---
